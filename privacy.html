1. 처리 목적과 항목

계정 관리와 보안을 위해 이메일, Firebase 사용자 ID, 인증정보, 로그인 제공자 정보, 제공한 이름·프로필 사진 및 IP 등 접속 정보를 처리합니다. 비밀번호 인증은 Firebase Authentication이 처리하며 앱은 비밀번호를 별도 파일에 저장하지 않습니다. 옷장·프리셋을 제공하기 위해 사용자가 입력한 이름, 나이, 소개, 메모, 키워드, 사진 및 의류의 상품명·브랜드·카테고리·치수·링크·즐겨찾기와 활동 알림을 기기에 저장합니다. 선택 정보는 입력하지 않아도 됩니다. 사용자 요청에 따른 저장·백업·공유와 계정 인증 목적에 사용하며 광고 타겟팅이나 개인정보 판매 기능은 제공하지 않습니다.

2. 사진과 권한

사용자가 촬영을 선택할 때 카메라 권한을 요청합니다. 사용자가 선택한 사진만 등록에 사용하며 마이크 녹음은 사용하지 않습니다. 권한을 거부해도 직접 입력할 수 있습니다. ML Kit는 사진·글자와 분석 결과를 기기에서 처리합니다. 별도로 Google은 설치 식별자, 기기·앱 정보, API 사용·오류·성능 통계를 진단·유지보수·품질 개선과 부정 사용 방지를 위해 처리할 수 있습니다. 사진 분석과 SDK 진단 전송은 서로 다릅니다. 자세한 안내: https://developers.google.com/ml-kit/terms 및 https://developers.google.com/ml-kit/android-data-disclosure

3. 저장과 보유기간

옷장·사진은 기본적으로 설치 기기에 저장됩니다. 사용자가 백업을 실행할 때만 사진을 포함한 백업 사본을 서버로 전송합니다. 평소 자동 동기화하지 않습니다. 가져오기는 사용자가 선택하며 병합 또는 교체할 수 있습니다. 직전 기기 자료는 되돌리기 사본으로 남을 수 있습니다. 기기 자료는 삭제·앱 데이터 초기화 시까지, 계정 정보는 탈퇴 시까지, 서버 백업은 교체·삭제·탈퇴 시까지 보관합니다. 로그아웃은 삭제가 아니며 로컬 자료가 남습니다. 앱 삭제 시 백업하지 않은 자료가 소실될 수 있습니다. 전자 자료는 삭제하고 종이 자료가 발생한 경우 파쇄 등으로 파기합니다. 법령상 보존 의무가 발생하면 근거·대상·기간을 안내하고 분리 보관합니다. 이메일 문의 자료는 요청 처리에 필요한 기간 보관하고 처리 목적이 끝나면 삭제합니다.

4. 처리위탁과 국외 이전

Google LLC의 Firebase 서비스를 계정 인증과 수동 백업에 이용합니다. 현재 Firestore 저장 위치는 대한민국 서울(asia-northeast3)입니다. Firebase Authentication은 미국에서 인증 정보를 처리합니다. 가입·로그인·세션 유지 시 이메일, 사용자 ID, 인증정보, 제공자 정보, 제공한 이름·사진, IP 등 접속 정보가 암호화된 네트워크로 전송됩니다. 목적은 계정 인증 및 보안입니다. 계정 유지 동안 처리되며 인증 IP 로그는 수 주, 탈퇴 후 인증 데이터의 운영·백업 사본은 180일 이내 삭제됩니다. 수탁자 문의 및 상세 안내: https://firebase.google.com/support/privacy 이용자는 인증 정보 국외 이전 동의를 거부할 수 있으나 인증이 필요한 앱 이용은 시작할 수 없습니다. 철회·삭제 요청은 설정의 계정 삭제 또는 운영자 이메일로 할 수 있습니다. ML Kit 진단 정보는 Google 개인정보처리방침에 따라 미국 등 Google 서버 운영 국가에서 처리될 수 있습니다. 정보의 종류·목적에 따라 보관기간이 달라지며 앱은 개별 SDK 로그의 보관기간을 정하거나 삭제하는 기능을 제공하지 않습니다. Google 개인정보 문의·보관 안내: https://policies.google.com/privacy 새로운 외부 분석 서비스를 제공할 경우 사진을 전송하기 전에 받는 곳·전송 항목·이용 목적을 안내하고 필요한 동의를 받습니다.

5. 공유와 외부 서비스

사용자가 실행한 프리셋 공유에는 프리셋 이름·메모·키워드, 작성자 이름·사진, 아이템 이름·브랜드·카테고리·사진·링크가 포함될 수 있습니다. 개인 나이·프로필 메모·상세치수는 공유 대상에서 제외됩니다. 사용자가 메모에 직접 적은 개인정보는 공유될 수 있으므로 확인해주세요. 수신자가 저장한 사본은 회수되지 않습니다. Google 사진 검색은 사용자가 선택하고 업로드를 확인한 사진을 Google에 전달하는 외부 서비스입니다. 기기 내 사진 분석과 구분되며 Google 방침이 적용됩니다. 검색 결과는 사용자가 확인하여 적용합니다. 상품 링크 입력 시 상품 사이트와 리디렉션 사이트에 접속하며 IP·요청 URL 등이 해당 사이트로 전달됩니다. 설문·개발자 의견 보내기는 Naver 설문으로 이동합니다. 사용자가 직접 제출하며 옷장 데이터가 자동 첨부되지 않습니다. 웹 안내 페이지의 호스팅 제공자 GitHub도 접속 정보를 처리할 수 있습니다.
